## Built
- Framework: `docs/brief.md` (approved), status, todo, decisions, guides (`docs/guides/testing.md`, `docs/guides/build-release.md`),
  `docs/features/performance.md`, a `docs/code/` mirror for every source file, `scripts/verify.sh` gate, eslint 10.13.0 (dev only).
- Tests: 37 unit tests (the shipped scripts in a node:vm sandbox) and 23 e2e tests (the built extension in Chrome for Testing over
  CDP, local HTTPS fixtures with frame-forbidding headers). No new runtime dependency.
- Security: the host page's own requests are no longer rewritten (was: CORP/nosniff stripped and cookies forced to `SameSite=None`
  on its fetches while a preview was open; Firefox rewrote every XHR in every tab). Rules no longer leak after a service-worker
  restart. A preview still hidden during the hold does not rewrite cookies.
- UX fixes: right/middle/Ctrl/Cmd-click inside the preview; drag and middle-button long press; modifier click on disabled sites;
  Space as close key; query-string navigation in the preview; host pages using `pushState` (Chrome); theme follows the system.
- Performance: the preview loads during the hold; hover sends nothing (in-page preconnect at press start); center stage pauses only
  running animations.
- Build: `tools/build.sh clean` deleted every zip in the repository tree, worktrees included; now only build output.
